D. RESTRUKTURISASI STRUKTUR CLEAN CODE — BRANCH `feat/clean-structure-modul2`
================================================================================
Tujuan: pisahkan tanggung jawab dengan tegas —
  * `src/app/`        -> HANYA routing / halaman (Expo Router)
  - `src/` (lainnya)  : komponen, context, hooks, constants, data, styles, types

Konvensi Expo Router (SDK 57) yang dipakai:
  `_layout.tsx`   = layout privat (navigator), bukan halaman
  `(tabs)/`       : route group (URL tidak berubah) — untuk bottom tabs
  `[id].tsx`      : dynamic route -> /dzikir/:id
  `[...slug].tsx` : catch-all route -> /panduan/*
  `+not-found.tsx`: fallback 404
  index.tsx       : halaman default sebuah folder

--------------------------------------------------------------------------------
D.1  Perbaikan yang dilakukan
--------------------------------------------------------------------------------
1) PINDAH LOKASI (dari root ke dalam src/) — sebelumnya salah taruh:
     constants/  -> src/constants/
     context/    -> src/context/
     hooks/      -> src/hooks/

2. HAPUS root `app/` yang merupakan duplikat lama (isinya versi home SEBELUM
   Modul 2: tanpa router.push, tanpa prop count). Expo Router memang mengabaikan
   `app/` root bila `src/app` ada, tetapi keberadaannya menyesatkan.

3. RENAME folder route group:
     src/app/((tabs)  ->  src/app/(tabs)      (kurung buka dobel itu salah)

4. RENAME fallback 404:
     src/app/not-found.tsx  ->  src/app/+not-found.tsx  (wajib diawali "+")

5. KONVERSI IMPORT KE ALIAS `@/`
   Memakai alias dari tsconfig (`@/* -> ./src/*`) supaya tidak lagi menghitung
   kedalaman relatif (`../../`) dan konsisten dengan arahan Modul 2.
   File yang diubah:
     - src/components/DhikrSelector.tsx
     - src/components/TasbihRing.tsx
     - src/components/ui/Header.tsx
     - src/components/ui/StartButton.tsx
     - src/components/ui/TargetInputRow.tsx
     - src/styles/components.ts
     - src/styles/global.ts
     - src/data/dhikr.ts
     - src/app/_layout.tsx
     - src/app/counting.tsx
     - src/app/recap.tsx
     - src/app/(tabs)/index.tsx
   Contoh: `../constants` / `../../constants` -> `@/constants`
           `../styles`  -> `@/styles`
           `../types/dhikr` -> `@/types/dhikr`

6. FILE BARU DIBUAT KOSONG (scaffold, 0 byte) — akan diisi bertahap:
     src/app/(tabs)/_layout.tsx
     src/app/(tabs)/history.tsx
